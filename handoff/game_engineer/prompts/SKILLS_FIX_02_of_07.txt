## B4. Extra projectiles: Javelin (max 4) and Aimed Shot (max 6)
Bow pick: **Aimed Shot**. It is the only rite that fires the bow's arrow bolt (`aimed`, shape bolt, "One arrow. Bow trait applies."); every other ranged rite is a spell. Giving it a D2 Multiple Shot spread turns it into the bow's main pack skill while the center arrow keeps it a single-target aimed shot, so nothing is lost.

- Count uses the **base rank only** (`ranks[id]`, not `j()` with +Rites from gear), so +Rites gear raises damage/AR but never the count and can't pass the cap. Synergy `synProj` (+proj) adds to the count but the cap still applies: `n = min(cap, countAt(baseRank) + synProj)`.
- One volley hits each foe at most once (volley id on each projectile; a foe already hit by this volley is skipped and the projectile continues/pierces). So a single target takes exactly the B3 hit; packs gain up to +150% (Javelin, 4) or +200% (Aimed Shot, 6) total. Each projectile rolls Attack Rating and crit on its own.

## E. Book synergies (153). 148 have no code; 5 are live (KEEP)
Now: `he()` stores `syn[key]=v` and `bp[key]` (breakpoint texts reached) and routes any % unit to damage. Do: in the **target rite's** cast/hit code read `v = p.syn["<t>:<id>"]` and `hit = (p.bp["<t>:<id>"]?.length ?? 0) > 0` and apply the effect by kind. Remove the generic `synDmg` routing except kind DMG. Kinds and helpers:
- **HIT** extra hit: `splash(x,y,1.5,v%·RD,elem)` at the place the effect names (impact, tip, foe). **BOLT**: `spawnBolt` per bolt/shard/jump for v%·RD (jumps/bounces: nearest foe within 3m). **DOT**: ground → `patches.push({x,y,life:2,max:2,dps:v%·RD})`; on foe → existing burn/poison/bleed with dps v%·RD for 3s (burn 1s if unit says so).
- **AREA**: multiply the named radius/range/width by (1+v/100) or add v meters (m units). **DUR**: add v seconds or ×(1+v/100) duration; s-units are flat seconds. **SPEED**: ×(1+v/100) speed / −v% cast or arming time for that rite only.
- **SLOW**: foe speed ×(1−v/100) for 2s (bosses half). **DEBUFF**: foe takes/loses v% (store on foe `synDebuff[key]` with 3s timer; read in the damage/defense/resist functions). **CRIT**: +v% crit chance on the named hits (cap 70%). **CHANCE**: roll v% per named event. **HEAL**: v% Max Life (or of the named amount) to the named member(s). **DEF**: +v% of the named stat to members for the stated time (default 3s). **COST**: target rite cost ×(1−v/100) into `synCost` (cap −50%). **DMG**: add to `synDmg` (existing, cap +100%). **OTHER**: as the effect text says, value v.
- Breakpoint text = extra effect once `hit` is true, exactly as written in the bp column. `st` column = status the effect applies (section F status table). `+proj` = +1 projectile (existing `synProj`).
- Tooltip, one line per synergy on both books: `{Source} → {Target}: {v:.1f}{unit} (cap {cap}). {effect}. At {bp}: {bp text}` (greyed until reached).
