STAGE 8: HERO WEAPONS BY EQUIPPED TYPE (3D hero only)

RULES
- Change only the 3D hero weapon/animation code (the hero rig class: buildKnight, parkSword, poseHero, playHero, startLight, finishClip, iT, DC). No game logic, balance, items, save, controls, UI or 2D renderer changes.
- If a step fails twice, stop and report. No retry loops. Build once, check the console, publish.

FACTS (live bundle)
- DC.heroWeaponUrl = weapon_sword_v2.glb. buildKnight() loads it, bones via sT(n,"mixamorigRightHand"|"mixamorigHips"|"mixamorigSpine2"), sockets hand/hip/back.
- parkSword(armed): hand = identity; hip = pos(.1105,.0394,.4039) quat(-.2023,.9157,-.3282,.112).
- iT = clip map {sword, peace, deaths}. oT(clip) strips hips root motion. rT = town set. finishClip swaps at ss_draw 42% / ss_sheath 67%.
- Weapon kind: game armKind() reads eq.weapon base+name -> "bow"|"staff"|"wand"|"axe"|"spear"|"mace"|"dagger"|"sword". twoHand(item): hands===2 or name has bow/staff. eq.shield is the offhand.
- Bow shots and wand bolts use the same attack: swingLen, swingT, swingHit = swingLen*.58 (arrow leaves at swingHit).

ASSETS (base https://raw.githubusercontent.com/bdblonewolf/sanctuary-assets/main/models/)
weapon_axe, weapon_greataxe, weapon_greatsword, weapon_bow, weapon_arrow, weapon_staff, weapon_wand, weapon_shield (.glb). All are pre-baked: identity offset in the grip bone = correct grip.

STEPS
1. Config: add DC.heroWeapons = {axe, greataxe, greatsword, bow, arrow, staff, wand, shield} URLs. Keep heroWeaponUrl for sword.
2. Loading: load each GLB once on first need, cache the scene, clone per use. A failed load warns once and falls back to sword.
3. Weapon set from equipped item: kind = armKind(). Map: sword/dagger/spear/mace -> sword; axe -> greataxe if twoHand or name has great/battle/war/double/broad, else axe; "great sword"/claymore/two-handed sword -> greatsword; bow, staff, wand as is. No weapon -> unarmed.
4. Clip sets in iT (all clips exist in knight_anim.glb):
 axe: idle axe_idle, walk axe_walk, run axe_run, light [axe_attack_1, axe_attack_2, axe_attack_3], heavy axe_attack_heavy, hit axe_hit, draw ss_draw, sheath ss_sheath.
 two-hand (greataxe, greatsword): idle gs_idle, walk ss_walk, run gs_run, light [gs_attack_1, gs_attack_2, gs_attack_3], heavy gs_attack_heavy, hit gs_hit, draw gs_draw, sheath axe_sheath.
 staff: idle magic_idle, walk magic_walk, run magic_run, light [magic_attack_2h, magic_cast_2h], hit magic_hit, draw axe_draw, sheath axe_sheath.
 wand: same with magic_attack_1h, magic_cast_1h, draw ss_draw, sheath ss_sheath.
 bow: idle bow_idle, walk bow_walk, run bow_run, shot bow_draw then bow_release, hit bow_hit, draw bow_equip, sheath bow_sheath.
 Keep iT.sword, peace, deaths. Death stays iT.deaths.
