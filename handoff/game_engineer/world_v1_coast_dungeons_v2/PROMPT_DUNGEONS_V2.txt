DNG2: Procedural Ashen Coast dungeons, Diablo-2 style (wrecks, sewer_coast, church_coast, tidecave). Applies AFTER PROMPT_WP1 (live, coast 90x180). Replaces DNG1 (do not apply DNG1). Towns and outdoor zones stay fixed; only dungeon insides are random. Data: https://raw.githubusercontent.com/bdblonewolf/sanctuary-assets/main/handoff/game_engineer/world_v1_coast_dungeons_v2/dungeon_rooms_v2.json
Rules: If a step fails twice, stop and report. No retry loops. Build once, check the console, publish. No Playwright. Add-only: don't edit martsirt_world.json, placements.json, interior JSONs, asset_version.txt, river/bridge/edge colliders, enemy AI/pathing. Martsirt is locked; no light or fog-look changes. Never gate or reduce the hero render pass. Blocking comes ONLY from solid tiles; col_* meshes stay hidden. Lite GLBs, single LOD, 512 textures, every mesh textured.
1. Add loadDungeonRooms() next to loadCoastV3(): fetch the URL with the same cache-bust helper (Hl(...)). On error console.warn('[dng2] failed', e) and change nothing.
2. Add genDungeon(areaId, seed) using a small seeded RNG (mulberry32). Rooms are 10x10; tiles are base-36 strings (tile enum in the file), solid '1' = blocked. Sockets N/S/E/W = 2 door tiles mid-edge (see file 'sockets').
3. rotate(room,k): k times 90deg CW: tile new[y][x]=old[9-x][y] (same for solid); every point (spawn, exit, spawns, loot, boss, quest) (x,y)->(10-y,x); sockets N->E->S->W->N. Always rotate the grid BEFORE any mesh or blocking is built.
4. Grow: cells map keyed "cx,cy". Place the entrance room at 0,0 with random k. open = its sockets. target = rand(count[0]..count[1]) - 1. While open and cells < target (max 300 tries): pop a random open socket (c,q); n = c + dir(q); skip if n is taken or the cell bounding box would exceed max_cells (6) on either axis. Pick a random room of kind corridor/corner/junction (dead_end too while more than 2 sockets are open); try the 4 rotations in random order and take the first that has socket opposite(q) and whose other sockets point to empty cells. Add it; push its other sockets to open.
5. Boss/quest: BFS from 0,0 through matching sockets; from the open sockets whose next cell is empty and in bounds pick the one farthest from the entrance; put the boss room there (or the quest room for church_coast), rotated so its single socket faces back. If none, or the final room count is outside count, retry with seed+1 (max 10 tries, then warn).
6. Seal: for every socket with no matching neighbour set its 2 door tiles to Wall b, solid 1. Stitch the cells into one W x H grid (cell * 10, origin = min cell). The outer ring is always solid.
7. Build the world from the final grid with the same world builder the existing interiors/dungeons use. Walls: on each solid tile touching a walkable tile, instance wall_glbs[style] (wrecks hull, sewer brick, church ruin, tidecave cliff) with random rotY in 90deg steps, scale 0.85-1.15, skip 1 in 4, dress_rocks_lite on corners. Solid tiles with no walkable neighbour get nothing. Water tiles (8) use the existing water material.
8. Content (positions are room-local after rotation + cell origin): entrance room: player spawn + exit {to:'coast', sx, sy} from room.exit. spawns[]: one random pack from area.packs via the existing coast pack spawner (zombie/corpse/imp). loot[]: chest/urn. Boss room: one elite of boss.kind named boss.name (Drowned Bosun, Drain Mother, Cairn-Keeper), chest on death. Quest points (church altar dng1_church, tidecave cairn SQ14_v3): tap spots that log '[dng2] quest <id>'. 1-2 random area props per non-entrance room on a walkable tile.
9. Seed: new seed (Date.now()^Math.random()*1e9) every time the player enters a dungeon from the coast; keep it while inside; rebuild and dispose the old dungeon world on the next entry from the coast. After each generation console.log('[dng2] '+id+' seed '+seed+' rooms '+k).
10. Coast triggers (in the coast world after applyCoastV3), arriving at the entrance room spawn: wrecks at (45.8,29.4) beside the existing 'flotsam' exit (44.6,28.2), which stays untouched. sewer_coast on the sewer stairs (60.6,19.8): if a live 'sewer' world already uses them and has quest use, add sewer_coast as a second stair 1 m east instead and report. church_coast: place the chapel lite exterior (bld_chapel_st_noll_shared_lite.glb) at (78.5,77.5) rotY 0, mark its footprint solid except the door tile (78.5,76.0) which is the trigger. tidecave at (17.5,151) with a bk_sea_dead + dress_rocks_lite cave mouth. Exits back land at wrecks (45.8,30.6), sewer (60.6,21.0), church (78.5,79.0), tidecave (17.5,153.5).
11. Build. Enter each dungeon twice from the coast and walk back once; report the four [dng2] logs (seeds must differ) and any warnings, then publish.
