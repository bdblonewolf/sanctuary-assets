# art_2d: art list

The 2D concept art, character/monster/boss sheets and still renders made by Brian's Grok Bot art bot (with NPC/monster still renders from the NPC builder and statue bot), committed Nov 1, 2026.
Each source folder's structure is kept (`sanctuary_art/`, `sanctuary_npc/`, `sanctuary_env/`). `refs_brian/` holds Brian's own reference images.
Total: 386 files, 215.3 MB. Plain path list: `art_paths.txt`.

Not included: Diablo/Blizzard mood screenshots (environment/refs), held quest/reputation files, video, raw third-party downloads, and work/src/tmp scratch.
